# magicel.de — SEO / GEO / AEO Mitbewerberanalyse + Maßnahmenplan

**Stand 2026-06-08.** Quellen: Wettbewerber-Seiten (live), Google Search Central (Primärdocs), BrightLocal, GO MO Group (llms.txt-Test), web.dev. 22 quellengeprüfte Findings (Deep-Research, 24 Quellen).

## TL;DR (die wichtigste Erkenntnis)
Programmatische Stadt-Seiten sind **kein Differenzierer** — alle Top-Mitbewerber (Gnann, Kuch, Zauberer Tim) machen das schon. Der Vorsprung kommt aus **(1) E-E-A-T/Trust, (2) echten Drittanbieter-Bewertungen, (3) Schema/Entity-Signalen, (4) echter Einzigartigkeit pro Stadt.** Die größten Hebel sind **Off-Page (GBP + Bewertungen + Presse/Backlinks)** — die kann nur der Inhaber ziehen. On-Page holen wir alles raus, was geht.

## A) ENTWICKLER — On-Page (mache ich)
**Priorität 1 — E-E-A-T front-loaden (höchster On-Page-ROI):**
- [ ] **Trust-/Credential-Leiste weit oben** auf JEDER Vorlagen-Seite (Stadt/Service/Anlass/Format): Awards (3× TV-Finalist, Greatest Talent 2023, Talents of Magic 2024, Dt. Jugendmeisterschaft Top 30, TVA 2025), quantifiziert (200+ Events seit 2016, 100+ Hochzeiten), **Marken-Logos größer & früher**.
- [ ] **„Über Emilian"-Mini-Block** (Foto + 2 Sätze + Credentials) — First-hand-Experience-Signal (Google E-E-A-T).

**Priorität 2 — Mehr informative, kundenfreundliche Sections (= auch Topical-Authority/AEO):**
- [ ] **„Was ist enthalten / Ablauf / Pakete"** — Transparenz (Dauer, Anfahrt, Technik, was inkl.).
- [ ] **„Welches Format für welchen Anlass?"** — Entscheidungs-Hilfe (Close-Up vs Bühne vs Magic Dinner) — ideal als AEO-Q&A.
- [ ] **FAQ vertiefen** (entity-reiche, konkrete Antworten — Strukturierte Daten heben AI-Extraktion +16–54 %).
- [ ] **Video / Show-Preview** prominent (haben wir, stärker einbinden).
- [ ] **Echte lokale Signale pro Stadt** (Venues/`bekannteLocations`, dated Testimonials) — Anti-Thin-Content.

**Priorität 3 — Schema erweitern (Entity/AEO; KEINE Stern-Rich-Results-Illusion):**
- [ ] **Person/Performer**-Schema für Emilian (awards, sameAs→Socials, knowsAbout, alumniOf). 
- [ ] **Service + Offer** (priceRange) je Format.
- [ ] **Review** (die 3 echten Bewertungen) + behalte `aggregateRating` **nur als Entity-Signal** — Google zeigt dafür KEINE Sterne (Self-Serving-Regel), das ist ok, kein Penalty.
- [ ] **`speakable`** für Hero/FAQ (AEO/Voice).
- [ ] Event/Offer-Schema auf Tickets.
- [ ] **Core Web Vitals** halten (LCP <2,5s, INP <200ms, CLS <0,1) — Prerender ist gut, prüfen.

**Bewusst NIEDRIG-Prio (Recherche: kein messbarer Nutzen):** `llms.txt` (kein großer AI-Bot nutzt es; Mueller/Illyes: Google unterstützt es nicht). Optional als No-Harm.

## B) INHABER (Emilian) — Off-Page (das bringt am meisten, nur du kannst es)
1. **Google Business Profile** anlegen/optimieren: **20 Service-Gebiete** (Städte, kein Radius) mit deinen Top-Zielstädten; bei reinem Service-Area-Business **Adresse ausblenden**. → Einziger Weg zu **Sternen in der Suche**.
2. **Bewertungs-Offensive**: nach JEDEM Event aktiv um **Google-Bewertung** (und ProvenExpert) bitten — Volumen ist der Hebel (Wettbewerber: 549 bzw. 900+). 
3. **Backlinks/Presse/E-E-A-T**: Magischer Zirkel/Verband, Event-Verzeichnisse, lokale Presse (TVA-Auftritt nutzen!), Kunden-Case-Studies, Hochzeits-Portale (z. B. Hochzeitsplaza, weddyplace). 
4. **Marken-Logos**: Freigaben sichern, prominent zeigen (so wie die Großen).
